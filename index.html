什么是凯利公式？

凯利公式用于计算在已知胜率和赔率的情况下，应该投入资金的最优比例，以实现长期资金增长最大化。

f* = (bp - q) / b

其中：b = 赔率-1，p = 胜率，q = 败率 (1-p)

什么是价值投注？

当你的预估胜率高于市场赔率隐含的胜率时，就存在价值投注机会。

价值 = 你的胜率 > 1/赔率

例如：你认为某队有 60% 概率赢，赔率为 2.00（隐含 50%），那么这就是一个价值投注。

关于数据源

本工具支持接入任何符合 RESTful 规范的足球数据 API。以下是推荐的数据源：

  • RapidAPI ⭐ — 推荐！免费额度充足，数据全面（球员、球队、比赛等）
  • football-data.org — 免费足球数据 API，包含各大联赛数据
  • api-football.com — 功能丰富的足球 API（有免费额度）
  • openfootball — 开源足球数据

提示：使用 RapidAPI 时，请先在 rapidapi.com 注册并获取 API Key。

配置 API 后，智能预测、球队查询等功能将自动获取真实数据。
