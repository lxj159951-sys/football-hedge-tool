# ⚽ 足球对冲工具

一个功能完整的足球博彩对冲计算和管理工具，纯前端实现，无需服务器。

## ✨ 功能特性

### 📊 计算工具
- **套利计算器** — 输入多平台赔率，计算是否存在套利机会
- **盘中对冲计算器** — 赛前下注后，赛中计算对冲金额锁定利润
- **凯利公式计算器** — 根据胜率和赔率计算最优下注比例
- **价值投注发现** — 对比预测概率和市场赔率，发现价值投注机会

### 🧠 智能分析
- **泊松分布预测** — 基于球队数据预测比赛结果概率
- **比分概率分析** — 计算各比分出现的概率
- **大小球预测** — 预测大/小球概率

### 📝 记录管理
- **投注记录** — 记录和管理所有投注
- **盈亏统计** — 自动计算胜率、ROI等指标
- **数据导出** — 导出为 CSV 文件

### 💰 资金管理
- **资金追踪** — 实时显示当前资金
- **止损提醒** — 达到止损线时自动提醒
- **盈利目标** — 达到目标时提醒
- **单次投注限制** — 设置最大投注比例

### 🔌 API 配置
- **自定义接口** — 支持接入任何足球数据 API
- **连接状态** — 清晰显示 API 连接状态
- **绝不造假** — 无数据时明确提示，不显示假数据

## 🚀 使用方法

### 本地使用
直接用浏览器打开 `index.html` 文件即可使用。

### 在线访问
部署到 GitHub Pages 后，通过访问链接使用。

## 📦 部署到 GitHub Pages

1. 在 GitHub 上创建新仓库
2. 将项目文件上传到仓库
3. 进入仓库 Settings → Pages
4. Source 选择 `main` 分支
5. 保存后即可通过 `https://username.github.io/repo-name` 访问

## 🛠️ 技术栈

- HTML5
- CSS3 (深色主题)
- JavaScript (原生)
- Chart.js (图表)
- Font Awesome (图标)
- localStorage (数据存储)

## 📱 响应式设计

支持电脑、平板、手机等各种屏幕尺寸。

## 📄 数据存储

所有数据存储在浏览器本地 (localStorage)，不会上传到任何服务器。
