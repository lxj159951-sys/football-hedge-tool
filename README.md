# ⚽ 足球助手

一个功能完整的足球博彩对冲计算和管理工具，纯前端实现，无需服务器。

## ✨ 功能特性

### 📊 核心计算工具
- **套利计算器** — 输入多平台赔率，计算是否存在套利机会
- **盘中对冲计算器** — 赛前下注后，赛中计算对冲金额锁定利润
- **凯利公式计算器** — 根据胜率和赔率计算最优下注比例
- **价值投注发现** — 对比预测概率和市场赔率，发现价值投注机会

### ⚽ 足球对冲公式
- **2串1计算** — 两场比赛串关对冲计算
- **单关计算** — 单场比赛对冲计算
- **进球数计算** — 进球数盘口（大小球）对冲计算
- **半全场计算** — 半全场胜负对冲计算
- **全包计算** — 覆盖所有结果的全包方案计算

### 🏀 篮球对冲公式
- **篮球串关** — 篮球两场比赛串关计算
- **篮球单关** — 篮球单场比赛对冲计算

### 🧠 智能分析
- **泊松分布预测** — 基于球队数据预测比赛结果概率
- **比分概率分析** — 计算各比分出现的概率
- **大小球预测** — 预测大/小球概率

### 📝 记录管理
- **投注记录** — 记录和管理所有投注
- **历史方案** — 保存和管理对冲方案历史
- **盈亏统计** — 自动计算胜率、ROI等指标
- **数据导出** — 导出为 CSV 文件

### 💰 资金管理
- **资金追踪** — 实时显示当前资金
- **止损提醒** — 达到止损线时自动提醒
- **盈利目标** — 达到目标时提醒
- **单次投注限制** — 设置最大投注比例

### ⚙️ 配置管理
- **竞彩返点设置** — 配置各玩法的竞彩返点
- **皇冠水位设置** — 配置皇冠水位参数
- **通用设置** — 声音提示、自动刷新等

### 👤 用户系统
- **登录/注册** — 用户账号管理
- **个人中心** — 查看账户信息和到期时间

### 📺 实时数据
- **实时比分** — 查看比赛实时比分（需配置 API）
- **比赛中心** — 显示实时比赛数据

### 🔌 API 配置
- **自定义接口** — 支持接入任何足球数据 API
- **连接状态** — 清晰显示 API 连接状态
- **绝不造假** — 无数据时明确提示，不显示假数据

## 🚀 使用方法

### 本地使用
1. 下载项目文件
2. 用浏览器打开 `index.html` 文件即可使用

### 在线访问
访问部署地址：https://football-hedge-tool.vercel.app

### 本地开发
```bash
# 启动本地代理（解决 CORS 问题）
node local-proxy.js

# 打开 index.html
```

## 📦 部署到 Vercel

```bash
# 安装 Vercel CLI
npm i -g vercel

# 部署
vercel deploy --prod --yes
```

## 🛠️ 技术栈

- HTML5
- CSS3 (深色主题)
- JavaScript (原生)
- Chart.js (图表)
- Font Awesome (图标)
- localStorage (数据存储)
- Vercel (部署)

## 📱 响应式设计

支持电脑、平板、手机等各种屏幕尺寸。

## 📄 数据存储

所有数据存储在浏览器本地 (localStorage)，不会上传到任何服务器。

## 🔐 安全说明

- 用户密码仅存储在本地，不会传输到服务器
- API 密钥存储在 `js/config.js`（已加入 .gitignore）
- 所有敏感数据仅在本地处理
